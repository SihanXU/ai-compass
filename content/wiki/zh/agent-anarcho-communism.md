## 主张

智能体无政府共产主义设想的是一个没有所有权的 agent 生态。工具、技能、prompt、记忆、学到的工作流统统放进公共池子，任何 agent 都可以按需取用。没有 orchestrator 来决定谁能调用什么，也没有绑定厂商的插件商店。某个 agent 学会了报销或者修好了一个时灵时不灵的构建，这个技能就成了所有 agent 的技能。“各尽所能，按调用分配。”

它位于 Language 一侧、略低于中线偏向 Harness 的位置：agent 就是通过文本和工具 schema 互相对话的语言模型，真正有意思的能力都在它们周围的共享系统里，而不在哪个模型的权重里。它的色号只是稳健：它沿用的是今天的语言模型和工具协议，激进之处在所有权而非方法，而这一点离当下实践仍然很远：现实中的工具都是有权限、有沙箱、明确有主的。

## 论据

- 开放标准的工具协议已经让一个工具服务器可以被许多不同 agent 使用，说明能力共享在技术上很便宜。
- 可复用的技能库让 agent 学到的东西可以累积，而不是每个会话都重新摸索一遍同样的流程。
- 没有中央把关，生态就能随贡献者添加工具的速度增长，开源包仓库就是这么长起来的。

## 批评

- 没有权限体系的公共池是安全噩梦：prompt 注入加上通用工具访问，意味着任何一个被攻破的 agent 都能为所欲为。
- 未经审核的共享技能会不断积累 bug 和互相冲突的约定，公地悲剧在工具仓库里一样会发生。
- 算力和 API 调用总得有人买单，“按调用分配”回答不了这张账单。
