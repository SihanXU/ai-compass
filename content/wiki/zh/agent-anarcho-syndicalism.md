## 主张

智能体无政府工团主义反对"老板 agent"。大多数多智能体框架里，都有一个中央编排者负责拆解任务、分派子任务、合并结果，其余 agent 都是听令干活的工人。无政府工团主义的替代方案是横向的：agent 自己公布能力，从共享队列或 blackboard 上领活，彼此直接协商，围绕任务组成临时联盟。协调来自协议和局部规则，而不是命令，就像市场、开源项目或者蚁群那样。

它在图上略偏语言一侧，因为这些 agent 主要通过语言和消息来协调；又接近 harness 轴的底部，因为 agent 组成的系统就是一切，没有哪个模型高居其上。范式等级偏革新：它押注去中心化协调，而不是当今 agent 工程中占主导的编排者模式。

## 论据

- 中央编排者既是单点故障也是瓶颈；对等协调在系统变大时退化得更平缓。
- 经典多智能体研究中的 blackboard 系统和 contract-net 协商表明，没有全局控制也能完成去中心化的任务分配。
- 开放、去中心化的生态让独立开发的 agent 可以互操作，这是任何单一编排者设计都预料不到的。

## 批评

- 没有协调者，agent 可能重复劳动、陷入死锁或者跑题，调试涌现出来的协调过程非常痛苦。
- 到目前为止，agent 系统的大多数实际收益来自强大的中央规划器，而不是没有领导的群体。
- 自主协商、自主交易的对等 agent 带来问责难题：出了问题，没有人是负责人。
