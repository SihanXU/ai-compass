## 主张

智能体唯我主义是一个环形称号，授予同时极度偏向 Language（x 低于 -0.7）和极度偏向 Harness（y 低于 -0.7）的测试者。它是左下角推到逻辑尽头的样子。agent 是包裹在记忆、工具、prompt 和工作流里的语言模型，而从 agent 的视角看，context window 之外什么都不存在：世界就是工具返回的东西，其他 agent 只是更多的文本，现实就是一次检索结果。与此同时，持有者花了太多时间调教自己的私人 agent，以至于它成了唯一显得真实的系统。

它在图上位于“语言为本体”与“harness 为手段”的交汇处：没有具身，没有世界模型，没有单一巨型模型，只有一套越来越精巧的个人上下文工程栈。主流的色号说明它并不要求新范式：它把现有的预训练语言模型当作既定前提，只是在外面越搭越多；笑点在于，一个完全自洽的 agent 分不清自己的工具和世界。

## 论据

- 对语言 agent 来说，上下文真的就是整个世界：表现极大地取决于检索到什么、记住什么、往 prompt 里放什么。
- 配上长期记忆和定制工具的私人 agent，对某一个人来说可能比通用模型有用得多。
- 把一切外部事物都当作工具接口后面的文本，提供了一个干净、统一、易于扩展的抽象。

## 批评

- 只通过自己的工具认识世界的 agent，无法察觉这些工具何时出错、过时或被操纵。
- 高度个性化的栈难以共享、评测或复现，经验教训只能锁在某个人的配置里。
- 忽视其他 agent、具身和物理世界，把 agent 限制在能完全用文本表达的任务里。
