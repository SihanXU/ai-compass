## 主张

游戏智能体主义认为，人工智能体学会行动的地方是游戏。游戏是一个有规则、有后果、有长程目标、有对手、有分数的世界，而且可以零成本重开一百万次。从棋类到即时战略再到开放世界沙盒，游戏每复杂一级，都逼出一种新能力：搜索、长程信用分配、部分可观测、多智能体博弈、开放式探索。通关游戏不是噱头，而是一套课程。

它在图上明显偏世界一侧，因为游戏是模拟环境，agent 在里面感知和行动，而不是阅读；又处在 harness 半区，因为现代游戏 agent 会把模型和搜索、技能库、记忆、游戏 API 组合起来。范式等级略偏革新：它历史悠久、战绩辉煌，却总能找到新前沿。

## 论据

- Atari、围棋、即时战略上的里程碑成果，各自带来了 DQN、价值网络加树搜索、大规模多智能体训练等技术，影响远远超出了游戏本身。
- Minecraft 这类开放世界游戏有开放式目标、工具合成和探索，是终身学习 agent 天然的试验场。
- 游戏提供精确、自动的奖励和完美的可复现性，这是大多数真实任务给不了的。

## 批评

- 超人类水平往往迁移不出去：在一款游戏里练成的本事很少能推广到另一款，更别说物理世界。
- 游戏专用 API 和特权状态信息，会让 agent 看起来比纯靠感知时能干得多。
- 野外机器人派指出，真实环境嘈杂、缓慢、无法重开，而这恰恰是游戏抽象掉的部分。
