## 主张

生成式小镇公社主义是 agent 研究里最温馨的一翼。它的奠基画面是一个沙盒小镇：二十来个语言模型 agent 起床、做早饭、上班、闲聊、记住彼此；当其中一个决定办派对时，邀请会一传十十传百，大家还真的准时到场。配方很简单：一条记录观察的 memory stream，定期 reflection 把记忆提炼成更高层的信念，再由 planning 把信念变成一天的日程。把它们放进同一个世界，就出现了没人逐行编排的社会行为。

它在图上略偏世界一侧，因为 agent 生活在一个有地点、物件和移动的空间化模拟世界里；又在 harness 半区下部，因为可信度来自包在模型外面的"记忆—反思—规划"架构。范式等级略偏革新。

## 论据

- Generative Agents 原始工作的消融实验表明，记忆、反思和规划各自都提升了人类评估者眼中 agent 的可信度。
- 模拟社区为社会科学问题和带长期记忆的 NPC 原型提供了廉价试验场。
- 小镇里的信息扩散和协作源自各个 agent 自己的记忆，而不是预先编好的事件。

## 批评

- "可信"不等于"准确"：模拟居民反映的是模型自带的刻板印象，把它们当真人替身可能会误导人。
- 让大量 agent 持续运行成本很高，时间一长行为也容易变得重复。
- 具身派指出，这个"世界"只是一张用文字描述的薄地图，对物理智能几乎说明不了什么。
