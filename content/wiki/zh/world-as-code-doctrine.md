## 主张

世界即代码主义同意 agent 需要世界模型，但对世界模型的"质料"有不同看法。与其在像素空间或 latent 空间里学习预测下一帧，不如把世界写成代码：带属性的物体、带前置条件和效果的动作、描述状态如何变化的规则。语言模型如今已是熟练的程序员，可以根据描述或观察起草这些模拟器，拿经验去测试，预测失败时再打补丁。代码让世界模型在已知之处精确、出错之处可查，还能直接拿来做规划和搜索。

它在图上明显偏世界一侧，因为关注的对象是环境及其动力学；又在 harness 半区下部，因为世界模型活在网络之外，是系统维护的一个可执行产物。范式等级偏革新，自我定位为符号规划和神经模拟之间的第三条路。

## 论据

- Code as Policies 一类工作用语言模型写出组合感知和控制 API 的程序来驱动机器人，说明代码是模型与物理世界之间实用的接口。
- 会写代码的模型能为复杂的机器人技能生成奖励函数（如 Eureka），有时还胜过专家手写的奖励。
- 显式的程序化世界模型支持精确的前瞻和搜索，而近似的神经模拟器在长时程上很难做到这一点。

## 批评

- 杂乱的连续物理、可形变物体和感知噪声，很难用人类可读的代码刻画。
- 合成出来的世界程序可能自信地出错，而且只在远离观测数据的地方才暴露。
- 视频世界模型派认为，学习型模拟器随数据扩展，而代码型模拟器只能随程序员（或模型）的工作量扩展。
